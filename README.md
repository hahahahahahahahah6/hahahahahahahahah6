# Hi, I'm Hao 👋

CS student at Pasadena City College (UC transfer, Fall 2027). I build developer tools for AI coding agents — the stuff I wish existed while shipping.

## What I'm building

- **[agent-guard](https://github.com/hahahahahahahahah6/agent-guard)** — Claude Code hooks that stop agents from cheating tests and making dangerous edits (now with an optional Nemotron semantic reviewer — [PR #3](https://github.com/hahahahahahahahah6/agent-guard/pull/3))
- **[browser-buddy](https://github.com/hahahahahahahahah6/browser-buddy)** — let Claude Code read your real logged-in browser via MCP
- **[memgovern](https://github.com/hahahahahahahahah6/memgovern)** — governance for agent memory: write and delete, not just store-and-search
- **[session-handover](https://github.com/hahahahahahahahah6/session-handover)** — handoff bridge between Claude Code and Codex sessions
- **[mcp-tax](https://github.com/hahahahahahahahah6/mcp-tax)** — audit how much context window your MCP servers eat
- **[model-canary](https://github.com/hahahahahahahahah6/model-canary)** — a degradation canary for your LLM API: probes the endpoint, fingerprints outputs, alerts on silent model swaps or throttling
- **[visa-slot-guard](https://github.com/hahahahahahahahah6/visa-slot-guard)** — U.S. visa appointment slot monitor with a resilient session engine (backoff, auto-relogin)
- **[fitlog-mcp](https://github.com/hahahahahahahahah6/fitlog-mcp)** — fitness tracking MCP server (Alexa+ / self-hosted)

All MIT-licensed, all on PyPI. I write about the builds on [dev.to/haoli](https://dev.to/haoli).
